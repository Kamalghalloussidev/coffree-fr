# Logos partenaires

Déposez ici les fichiers de logos référencés par la section « Partenaires » de [`index.html`](../../../index.html).

| Partenaire | Nom de fichier attendu |
|------------|------------------------|
| Cdiscount | `cdiscount.png` |
| Provencia / Carrefour / Carrefour Market | `provencia.png` |
| Groupe SAMSE | `groupe-samse.png` |

**Recommandations :**
- Format `.png` (fond transparent) ou `.svg` de préférence.
- Hauteur d'au moins ~140 px pour rester net (la grille redimensionne à 72 px de haut max).
- Si vous changez un nom ou un format, mettez à jour les attributs `src` dans la section `#partenaires` de `index.html`.
